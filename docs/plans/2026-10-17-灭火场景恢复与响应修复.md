# 灭火场景恢复与响应修复

用户明确选择恢复早上的“青岚县北山林火”：火场、火线、队伍、三方案及每分钟命令建议；接入现有人员物资、九步和五步复盘，并修复点击迟缓。

## 范围

1. 原18702灭火演示及18703人员物资演示的数据、源码、报告和证据保留。新建独立整合交付根，先在隔离端口验证，再使用原18703地址提供新演示；原目录不覆盖。
2. 同一只读请求/后台只读核对内复用审计检查及快照加载，作用域结束即丢弃；新请求和写入继续独立校验。减少重复计算与后台轮询积压，不通过删除校验换速度。
3. 新演示沿早上22条模拟空间资料、原火场坐标和三方案语义展开；人员名册、扫码到场、保障需求、任务部署/变更/执行/独立核验、九步记录和阶段报告引用同一新模拟事件。不是修改旧事件标题或拼接两个事件的历史。
4. 保留每分钟推进、人工决定时暂停、拒绝不假造完成等交互。模拟业务过程明确留证，旧临时播放不伪装为原始业务审计。
5. 保持餐食照明等遗留与火情活动状态；阶段报告不自动发布。真实接口、模型、专业预测和真实新闻发送不在本轮。
