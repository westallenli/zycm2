# 破局智援参谋：电脑与队长手机同网演示

本版本用于模拟演示。电脑和手机连接同一个可信 Wi-Fi，电脑保持开机运行；不需要安装 App，不需要服务器和域名。

## 启动与访问

1. 如果原演示正在运行，先运行交付目录中的“停止演示.ps1”，等待正常结束。
2. 使用 PowerShell 7 运行本目录的“启动同网手机演示.ps1”。它自动读取本机内网地址，启动电脑及手机入口；不要重复启动。
3. 电脑打开 <http://127.0.0.1:18703/wifi>，手机用相机或扫一扫打开页面上的二维码。也可在手机浏览器输入启动脚本显示的地址。
4. 当前电脑地址为 `192.168.1.37` 时，手机入口为 <http://192.168.1.37:18705/mobile>。地址可能随网络变化，应以每次启动脚本及电脑二维码页为准。
5. 本次模拟待到场队长账号：`13900000031`，密码：`123456`。电脑端演示副总指挥账号：`13900000120`，密码相同。

## 队长手机操作

- 召集回执：填写能否出动、预计人数和预计到场时间。回执不自动变成实际到场。
- 队伍到场：扫描事件二维码登录，确认载入本队名册。首次到场仅勾选未到人员，再提交；后续补到单独勾选，随队物资不重复计入。队长可报告所选已到人员的待命等状态。
- 任务接收：查看本人正式任务并明确接收、确认条件、开始执行。没有任务时显示等待提示；打开页面不会自动接收。
- 执行回报：报告本人任务进度或完成，完成申报仍待指定人员核验。

电脑端刷新相关模块即可看到手机操作；两端共用同一份演示状态。测试记录来自独立副本，没有覆盖当前演示数据。

## 打不开与停止

- 手机先关闭移动数据或确认正在使用同一 Wi-Fi。访客网络、AP 隔离或单位网络策略可能禁止设备互访，需要换可互通网络或请网络管理员处理。
- 电脑浏览器能打开手机地址而手机打不开时，先核对 Wi-Fi 和地址；防火墙仍拦截时，才以管理员身份运行本目录“允许同网手机访问.ps1”。它只允许当前内网地址、手机端口及同一子网，不关闭防火墙。本机已有 Python 放行规则，本次没有修改防火墙。
- 退出浏览器不会停止服务。结束演示请运行“停止演示.ps1”；它同时停止电脑和手机入口。电脑休眠、关机或服务停止后，手机不能访问。
- 当前原“启动演示.ps1”仍是仅电脑入口；手机演示请使用新的“启动同网手机演示.ps1”。
