## 三个主入口

- 沙盘：查看当前事件地图和已登记态势，可拖动、双指或加减缩放，点击标记看详情。地图不是手机实时定位，不采集GPS。底图或资料未接入时明确显示，不编造位置或天气。
- 本队命令：只显示下达给本人负责队伍的命令。完成后点击“提交完成回复”，填写回复并提交。队长是具名操作人，执行对象是队伍；回复保留为待上级核验的申报，不会自动关闭原命令。
- 助手：查询本事件已有火情、气象、队伍、本队命令、物资和风险资料。返回来源和资料时间；没有资料明确说明。此为系统内资料查询，没有接入外部实时天气、手机定位或新的模型服务。

## 两个快捷按钮

- 到场扫码：允许App相机权限后，扫描电脑安装页下方的“现场到场码”（不是上方安装码），再确认本队到场。整队按配置名册满编计入，不填写人数、不核对缺员、没有补到操作。重复扫描不重复计人或物资；未扫码的队伍不自动到场。相机画面只在本机解码，不保存或上传。
- 物资缺乏：只填写缺少的物资名称并提交。不要数量、配送地点、需求时间、原因或说明；事件、队伍和提交时间由系统关联。多个本人负责队伍时只需选择队伍，不涉及个人。

电脑端在现有“本火情人员与物资”查看缺物回报，在任务执行回报模块查看队伍完成回复。命令完成回复与物资回报不自动扣改库存、不直接发布任务或核验完成。

提交中按钮锁定；连接或保存未确认时保留输入，先刷新核对，不自动重试。退出账号在App内操作。电脑“停止演示.ps1”同时停止两端服务。访客Wi-Fi/AP隔离可能阻止设备互通；先核对网络和地址。本次没有修改防火墙。

## 0.3 大地图与信息上报

沙盘地图自动铺满主区域，顶栏为事件和到场状态；右上角“⋯”可看事件/地图详细信息、刷新、重试底图、查看本队上报记录、切换事件和退出。底部保留沙盘/本队命令/助手。地图下方为扫码到场/信息上报/物资缺乏，按钮外观紧凑、点击区48dp。切换页签及资料刷新复用已有地图和视角，地图源变化重新取图。

信息上报：填写现场情况，可选拍照或选照片，最多3张。图片先在手机缩小、纠正方向、去除原始元数据并压缩为JPG，每张≤1MiB；点击缩略图预览，可移除。联网提交期间显示上传状态；失败保留当前窗口的文字照片，原样重试使用同一请求编号，不重复登记。未提交草稿仅在当前App运行中保留，不保证系统终止App后恢复，不是断网队列。

照片原始采集时间/位置不从EXIF推定；上报时间为服务器收到并登记的时间。电脑沙盘智能参谋资料清单有“队伍现场信息上报·待核实”，可查看照片；手机菜单“我的上报记录”也可查看。助手读取本事件上报文字和照片数量，不自动识图、核实或定位。照片只按需读取，不随地图刷新整批传输。真实手机拍照/选图/触控仍需实装验证。
