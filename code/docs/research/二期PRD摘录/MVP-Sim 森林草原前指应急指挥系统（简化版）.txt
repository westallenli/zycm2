二、范围（MVP Only）
✅ In Scope
统一身份 & 组织（2 层：省-市-队伍）
任务创建 → 二维码 → 扫码入岗
上传火场 Shapefile → 手绘隔离带 → 30 m 缓冲区 → 导出 Shapefile
物资库 → 二维码出入库 → 库存预警（安全库存 20%）
一键复盘：自动拉数据 → 1 页 PDF
❌ Out of Scope语音对讲、北斗、大屏三维、国密、三员分立、语音转写、AI 预测

五、数据模型（核心表）
sql
复制
-- 统一身份user(id, name, phone, unit_code, status, pwd_hash, create_time)
unit(code, name, parent_code)
-- 任务与入岗
task(id, name, create_time)
qrcode(id, task_id, role_name, url)
person(id, task_id, role_name, name, phone, join_time)
-- 火图与隔离带
fire_layer(id, task_id, filename, geom, upload_time)
isoline(id, task_id, geom, buffer_geom, length_km, create_time)
-- 物资
item(id, name, spec, unit, safe_stock)
stock(id, item_id, qty, warehouse)
stock_flow(id, item_id, type, qty, operator, time)
-- 复盘
report(id, task_id, pdf_url, create_time)
六、核心接口（精简）
复制
POST /user/batch              // Excel 批量导入
POST /task                    // 新建任务
POST /qrcode/batch            // 生成二维码
POST /person/join             // 扫码加入
POST /fire/layer              // 上传火场文件
POST /isoline/draw            // 保存隔离带
GET  /isoline/export          // 导出 Shapefile
POST /stock/scan/in|out       // 扫码出入库
GET  /stock/warn              // 库存预警列表
POST /report/auto             // 一键生成复盘 PDF
GET  /report/download         // 下载 PDF
七、原型线框（手绘→可直出）
复制
