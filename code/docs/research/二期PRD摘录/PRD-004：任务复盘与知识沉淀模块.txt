PRD-004：任务复盘与知识沉淀模块
版本：v1.0作者：产品经理-××创建日期：2025-12-02评审截止：2025-12-07需求来源：建设方案 §2.6 + 省局战训处访谈纪要
1. 背景与目标
表格
复制
| 项目 | 说明 |
| 用户痛点 | ① 复盘靠人工整理微信/录音，耗时 2-3 天；② 经验分散在个人电脑，无法跨火灾复用；③ 缺少量化指标，同一错误重复出现。 |
| 业务目标 | 复盘报告生成时间 ≤30 分钟；关键经验 100% 入库；同类火灾复用方案率 ≥50%。 |
| 产品目标 | 提供“数据自动汇聚→报告一键生成→经验智能推荐→案例库全文检索”的闭环；支持复盘推演、版本对比、权限脱敏。 |

2. 范围
In-Scope
自动数据采集、复盘报告生成、在线推演回放、经验案例库、全文搜索、权限脱敏、版本管理。
Out-of-Scope
AI 自动生成改进建议（v1.5 引入）
与干部绩效考核系统对接（v2.0）
3. 用户角色
表格
| 角色 | 职责 | 频次 |
| 复盘员 | 发起复盘、补充缺失数据 | 高 |
| 指挥长 | 审阅报告、批示改进意见 | 中 |
| 战训参谋 | 搜索历史案例、编制教案 | 中 |
| 系统管理员 | 设置脱敏规则、归档案例 | 低 |

4. 功能需求（Story → AC）
表格
| 编号 | 用户故事 | 验收标准（AC） | 优先级 |
| 4.1 | 作为复盘员，我希望系统在任务结束后自动拉取全流程数据，减少人工复制粘贴。 | 1. 自动抽取：人员签到、路径轨迹、资源流水、通讯记录、传感器数据2. 缺失数据红色标注，可一键补录模板3. 耗时 ≤5 分钟完成汇聚 | P0 |
| 4.2 | 作为复盘员，我希望能一键生成标准化复盘报告，并可导出 Word/PDF。 | 1. 报告模板：封面→概况→组织→资源→行动→问题→建议→附件2. 图表自动生成：到岗时效直方图、资源到位率饼图、路径偏差热力图3. 导出格式：Word 可编辑、PDF 正式归档 | P0 |
| 4.3 | 作为指挥长，我希望能在线回放火场态势与队伍轨迹，如同“录像机”。 | 1. 时间轴滑块，播放速度 1×-8×2. 图层随时间自动显隐：火线、隔离带、队伍位置3. 支持暂停、单步前进，便于讲解 | P0 |
| 4.4 | 作为战训参谋，我希望能把复盘报告一键归入“案例库”，并打上多维度标签。 | 1. 标签：火因、地形、植被、风速、战法、规模、扑救时长2. 支持批量打标签、自定义新标签3. 归入后生成唯一案例编号，不可物理删除 | P1 |
| 4.5 | 作为战训参谋，我希望能通过自然搜索快速找到相似案例，并对比关键指标。 | 1. 搜索框支持：关键词、时间范围、标签多选2. 结果列表显示：相似度% + 关键指标对比条形图3. 点击可跳转到案例详情 | P1 |
| 4.6 | 作为系统管理员，我希望能对敏感信息自动脱敏，满足公开共享要求。 | 1. 规则：手机号、身份证、地名（可选）自动打*2. 脱敏后版本独立存储，原日志仅管理员可见3. 支持预览脱敏效果 | P1 |
| 4.7 | 作为复盘员，我希望能对报告进行版本管理，追踪每次修改内容。 | 1. 每次“保存”生成新版本 V1→Vn2. 对比视图：高亮段落增删3. 可回滚到任意历史版本 | P2 |
| 4.8 | 作为系统，我希望支持复盘推演模式，允许用户调整参数并重新模拟路径。 | 1. 提供“推演”按钮，进入副本环境2. 可修改：出发时间、队伍数量、装备类型3. 系统重新计算耗时、资源消耗，并生成对比报告 | P2 |

表格

6. 原型 & 流程
（1）页面流转任务列表 → 一键汇聚 → 报告编辑 → 在线回放 → 归入案例库 → 搜索/对比
（2）关键线框① 汇聚页├─ 数据完整性仪表板：100% 绿色 | 缺失 3 项红色├─ 【一键补录】【生成报告】
② 报告页左侧：章节导航右侧：图表自动插入（可拖拽调整顺序）顶部：【导出 Word】【导出 PDF】【保存版本】【在线回放】
③ 回放页底部时间轴：2025-11-28 14:00 ▶️─────── 18:00速度：1× 2× 4× 8× | 暂停 | 单步▶│
④ 案例搜索搜索框：“ wind 灭火 + 坡度 > 25 ° ” → 结果：相似度 92% 案例编号 F20251015-汉中 | 关键指标对比条
（3）时序图（核心）前端→后端：POST /review/autoCollect → 返回缺失列表前端→后端：POST /review/report → 返回报告 ID & 下载链接前端→后端：WebSocket /replay/data → 推送时间序列 GeoJSON前端→后端：POST /case/store → 返回案例编号

9. 验收方案
表格
