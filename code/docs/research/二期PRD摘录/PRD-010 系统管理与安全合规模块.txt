PRD-010 系统管理与安全合规模块
版本：v1.0作者：产品经理-××创建日期：2025-12-05评审截止：2025-12-10需求来源：等保 2.0 三级、《陕西省森林草原火灾应急预案》信息化章节、厅网信办合规检查清单
1. 背景与目标
表格
复制
| 项目 | 说明 |
| 用户痛点 | ① 账号无唯一标识，一人多号、离职未注销；② 操作日志分散，无法关联到个人；③ 数据无分类分级，敏感信息明文存储；④ 等保测评 73 项条款逐条补材料，重复返工。 |
| 业务目标 | 等保 2.0 三级一次通过；敏感数据 100% 加密；账号生命周期 100% 自动化；重大操作审计追溯 ≤5 min。 |
| 产品目标 | 提供“账号统一+权限 RBAC+数据分级加密+日志审计+安全基线+灾备演练”一站式安全合规中台；支持三员分立、密评备案、测评材料一键导出。 |

2. 范围
In-Scope
统一身份、RBAC、数据分级加密、日志审计、三员分立、安全基线、漏洞扫描、备份灾备、等保材料导出。
Out-of-Scope
物理机房 UPS、消防、门禁（已固化）
商用密码产品国密型号鉴定（v2.1）
3. 用户角色（三员分立）
表格
| 角色 | 职责 | 备注 |
| 系统管理员 | 创建账号、分配角色、启停用 | 不能查看审计日志 |
| 安全管理员 | 授权/回收、制定策略、审计查询 | 不能创建账号 |
| 审计管理员 | 查看日志、出具报表、归档证据 | 不能授权 |

4. 功能需求（Story → AC）
表格
| 编号 | 用户故事 | 验收标准（AC） | 优先级 |

| 4.2 | 作为安全管理员，我希望能按 RBAC 进行授权，支持数据级行权限。 | 1. 角色→菜单→数据范围三级授权2. 数据范围：本人/本部门/本县/本市/全省3. 授权变更短信+站内提醒 | P0 |
| 4.3 | 作为系统，我需对敏感数据自动加密，并提供密钥轮换。 | 1. 敏感字段：手机、身份证、坐标、伤情描述2. 加密算法：AES-256-GCM，密钥托管 KMS3. 轮换周期 90 天，旧密钥解密无感 | P0 |
| 4.4 | 作为审计管理员，我希望能一键导出等保 2.0 三级所需全部材料。 | 1. 模板内置：管理制度、问卷、截图、日志样例2. 一键生成 ZIP，含 73 类文件夹，命名符合测评中心要求3. 导出耗时 ≤5 min | P0 |
| 4.5 | 作为系统，我需对重大操作进行双重鉴别，防止越权。 | 1. 重大操作：授权变更、数据导出、参数修改2. 二次鉴别：短信验证码+指纹/人脸识别3. 失败 3 次锁定 30 min | P1 |
| 4.6 | 作为安全管理员，我希望能查看实时安全评分，并对不合规项一键修复。 | 1. 评分维度：账号、权限、加密、日志、补丁2. 不合规项给出“修复脚本”或“操作指引”3. 修复后评分实时更新 | P1 |
| 4.7 | 作为系统管理员，我希望能对账号进行生命周期管理，离职自动停用。 | 1. 对接 HR 系统，每日同步离职名单2. 离职当日 18:00 自动冻结，冻结后无法登录3. 冻结 30 天后自动归档，数据脱敏 | P1 |
| 4.8 | 作为系统，我需对数据进行每日异地备份，并提供一键演练。 | 1. 备份策略：全量每日、binlog 每小时2. 异地距离 ≥300 km，RPO≤1 h3. 提供“一键演练”按钮，生成演练报告 | P2 |

5. 非功能需求（摘选等保关键项）
表格
| 类别 | 要求 |
| 性能 | 账号授权接口 ≤200 ms；加密字段查询解密 ≤100 ms |
| 兼容 | 支持国密 SM4/SM3 可选；LDAP 协议 v3 |
| 安全 | 密码策略：12 位+大小写+数字+特殊字符，90 天更换，历史 5 次不重复 |
| 可靠 | KMS 双活，主故障 5 s 内切换；备份数据定期校验，损坏自动告警 |

6. 原型 & 流程
（1）页面流转统一身份 → 授权中心 → 数据分级 → 日志审计 → 安全评分 → 等保导出 → 备份演练
（2）关键线框① 统一身份中心├─ 创建账号：姓名+手机+身份证+组织+有效期├─ 批量导入：Excel 模板下载 【导入】└─ 离职同步：HR 系统 每日 18:00 自动冻结
② 授权中心角色：指挥长 数据范围：本县【保存】→ 短信通知用户
③ 安全评分仪表盘总分：92/100 ▓▓▓▓▓░不合规：3 项 【一键修复】
④ 等保材料导出选择测评年度：2025【一键导出】→ 生成 ZIP，大小 ≤50 MB
（3）时序图（核心）前端→统一身份：POST /user → 返回 userId前端→授权：POST /role/assign → 返回授权号前端→KMS：POST /key/rotate → 返回新密钥版本前端→审计：GET /audit/export → 返回 ZIP 下载链接

9. 验收方案（对标等保 2.0 三级）
表格
| 场景 | 步骤 | 通过标准 |
| 账号唯一 | 导入相同身份证 2 次 | 第二次失败，提示“身份证已存在” |
| 数据加密 | 查询手机字段 | 返回密文，解密后明文正确 |
| 等保导出 | 点击“一键导出” | 生成 73 类文件夹，命名符合测评中心要求，耗时 ≤5 min |
| 异地备份 | 点击“一键演练” | 15 min 内完成恢复，RPO≤1 h，演练报告得分 ≥90 |
| 三员分立 | 系统管理员尝试查看审计日志 | 提示“无权限”，需审计管理员登录才可查看 |
