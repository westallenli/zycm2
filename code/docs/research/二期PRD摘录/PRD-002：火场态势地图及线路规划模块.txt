PRD-002：火场态势地图及线路规划模块
版本：v1.0作者：产品经理-××创建日期：2025-12-01评审截止：2025-12-06需求来源：建设方案 §2.4 & 一线指挥员访谈纪要
1. 背景与目标
表格
| 项目 | 说明 |
| 用户痛点 | 火场态势更新慢、路径靠经验手绘、多组行军路线冲突，导致隔离带打偏、队员迷航。 |
| 业务目标 | 态势图 5 分钟内全员同步；路径规划耗时 ≤3 分钟；路线冲突检测准确率 ≥90%。 |
| 产品目标 | 提供“态势一张图、路径三键成、冲突实时告警”的闭环功能；支持离线底图、断网缓存。 |

2. 范围
In-Scope
态势图上传/叠加/版本管理、交互式路径绘制、冲突检测、离线底图、一键推送路径到移动端。
Out-of-Scope
无人机实时视频流（v1.3 接入）
火势蔓延预测模型（v1.4 接入）

表格

| 指挥长 | 审批态势图、绘制主力路径 | 中 |
| 小组队长 | 接收路径、实时回传位置 | 高 |

5. 非功能需求
表格
| 类别 | 要求 |
| 性能 | 上传 20 MB Shapefile 解析 ≤15 s；冲突检测 ≤3 s（100 km 路径） |
| 兼容 | 支持 Leaflet/Mapbox GL JS、Chrome≥80、微信内置浏览器 |
| 安全 | 上传文件格式白名单 + 病毒扫描；路径数据 HTTPS 加密传输 |
| 可靠 | 离线包双重存储（OSS + 本地 NAS），丢失可 5 min 内恢复 |

6. 原型 & 主要流程
（1）页面流转态势上传 → 图层列表 → 路径绘制 → 冲突检测 → 保存 → 推送 → 移动端查看
（2）关键线框① 图层侧栏├─ 火势边界 V2 (透明度▼)├─ 隔离带 V1├─ 主力路线 A└─ + 添加图层
② 路径绘制工具条【绘路径】【测距】【撤销】【保存】【推送】
③ 冲突弹窗检测到 2 处冲突├─ 扑救三组 vs 空中作业组 长度 120 m└─ 【自动避让】【强制保存】
（3）时序图（核心）Web→后端：POST /situation/upload → 返回 layerIdWeb→后端：POST /path/detect → 返回冲突列表Web→后端：POST /path/push → 生成离线包推送任务移动端←推送：WS 消息 /topic/path/{taskId}
7. 数据模型（核心字段）
表：layerid | task_id | name | type(enum:shp,kml,geojson) | url | version | creator_uid | ctime …
表：pathid | task_id | name | geometry(LineString) | length_km | duration_min | conflict_count | creator_uid | ctime …
表：path_push_logid | path_id | pos_code | push_time | read_time | mobile_id …
8. 接口清单（关键）
表格
| 接口 | 方法 | 说明 |
| /situation/upload | POST | 上传文件返回 layerId |
| /layer/{id} | DELETE | 删除图层 |
| /path/detect | POST | 冲突检测 |
| /path | POST | 保存路径 |
| /path/push | POST | 推送路径到移动端 |
| /offline/package | GET | 下载县域离线包 |

9. 验收方案
表格
复制
| 场景 | 步骤 | 通过标准 |
| 上传叠加 | 上传 18 MB 火场边界 Shapefile | 解析 ≤15 s，地图可见新图层，版本 V1 |
| 冲突检测 | 绘制 2 条相距 25 m 路径 | 系统高亮红色，列出冲突，避让后冲突消失 |
| 离线查看 | 关闭网络，打开移动端地图 | 底图、路径仍可平移缩放，无闪退 |
| 推送时效 | 点击推送→移动端收到 | 延迟 ≤3 s（4G），已读状态回传正确 |
