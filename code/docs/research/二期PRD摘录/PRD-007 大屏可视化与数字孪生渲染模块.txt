1. 背景与目标
表格
复制
| 项目 | 说明 |
| 用户痛点 | ① 大屏仅二维地图，缺乏高程与建筑白模，指挥员需脑补火势蔓延；② 多源数据（卫星、无人机、前指）分屏显示，无法一眼统览；③ 复盘汇报需重新制作视频，耗时 2-3 天。 |
| 业务目标 | 火势三维蔓延展示延迟 ≤30 s；汇报视频一键生成 ≤5 min；大屏帧率 ≥25 fps；孪生场景加载 ≤10 s。 |
| 产品目标 | 提供“三维地形+建筑白模+实时火场+资源轨迹+一键录屏”的数字孪生大屏；支持离线包、多屏联动、触控标注。 |

2. 范围
In-Scope
三维地形、建筑白模、实时火点、隔离带、队伍轨迹、一键录屏、多屏联动、触控标注、离线包。
Out-of-Scope
室内 BIM 级建模（v2.0）
火焰粒子特效电影级（v2.1）

6. 原型 & 流程
（1）页面流转大屏启动 → 场景加载 → 二维/三维切换 → 图层控制 → 标注/录屏 → 生成视频 → 快照保存
（2）关键线框① 大屏主界面顶部工具栏：【二维】【三维】【录屏】【快照】【更多】左侧图层树：地形、白模、火点、隔离带、轨迹……底部时间轴：回放控制
② 三维模式视角：35° 俯视角，北向 0°火点：红色粒子高度 5 m隔离带：红色半透明围栏，高度 3 m
③ 录屏设置弹窗分辨率：1080p 帧率：25 麦克风：开/关【开始录制】【停止】
④ 多屏联动示意左屏（2D）缩放到 1:5000 → 右屏（3D）同步相机位置，延迟 ≤200 ms
（3）时序图（核心）前端→后端：WebSocket /scene/snapshot → 保存快照前端→GPU：捕获帧纹理 → ffmpeg.wasm → MP4 → 后端 → 返回下载链接触控屏→WebSocket：/annotation/add → 广播给所有客户端
