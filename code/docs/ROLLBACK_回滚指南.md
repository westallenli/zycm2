## 改坏了怎么回

在本目录按住 Shift 右键 →「在此处打开终端」，然后：

| 情形 | 命令 | 效果 |
|---|---|---|
| 只改坏了代码，想全部丢掉 | `git checkout -- .` | 回到最近一次提交 |
| 想回到某个基线 | `git reset --hard v736`（或 `v725`／`v657`） | 所有跟踪文件还原为该标签状态（会丢弃未提交改动，执行前想清楚） |
| 只想看某版长什么样，不动工作树 | `git switch --detach v725` 看完 `git switch -` | 临时切过去，不产生改动 |
| Git 仓库本身坏了 | 关闭服务，把对应 zip 解压覆盖本目录 | 整库还原 |

回滚后照常双击 `启动熊猫智脑.bat` 即可；`impl\data\work\` 每次启动自动重建，无需处理。

## 以后每做完一批这样保存

```
git add -A
git commit -m "说明这批做了什么"
git tag -a v新基线号 -m "一句话内容与回归数"
git archive --format=zip -o "..\备份\熊猫智脑v4_快照v新基线号_日期_时分.zip" v新基线号
```

要点：

- `git archive` 只打包**已提交**的内容，不会把 `data\work\` 工作副本和 `__pycache__` 混进备份；
- zip 文件名带日期时分，**只做新增，不覆盖既有快照**；
- 打完包当场验一次：`git status --short` 应为空，`git tag --list` 应含新标签，`unzip -l` 或解压后确认 `impl\panda_brain\`、`docs\`、`启动熊猫智脑.bat` 都在。
