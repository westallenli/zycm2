# 19　离线地图包获取与放置指南（V1.0）

2026-08-26 与沙盘指挥页同批落地（docs/18 第 17 章「本地地图优先」的执行配套）。

## 一、系统已经支持什么

沙盘指挥页地图源（右上「图例/图层」内单选，即时切换）：

| 来源 | 联网 | 说明 |
|---|---|---|
| 高德地图／高德影像（在线） | 需要 | 默认源，国内网络直连可用，中文注记 |
| 开放街道地图（在线） | 需要 | 部分网络不可达时会自动横幅提示，不作为默认 |
| 本地离线瓦片包 | 不需要 | 检测到即自动成为默认源，断网可用作战 |

在线高德底图为国内加密坐标，与标绘数据存在数十至数百米级偏移，页面图例已常驻该提示；
要「上图位置即所得」，请用离线瓦片包（按你选的数据源定精度），或在图上以人工粗略对齐为准。

## 二、放哪里（只认这一个目录）

    impl/data/offline_map/

两种形态任选其一（放好刷新 /sand 即生效，无需改代码、无需重启）：

1. **XYZ 目录**（推荐，工具通用导出格式）：
   offline_map/tiles/{级别z}/{列x}/{行y}.png（支持 .png/.jpg/.webp；
   也可省略 tiles/ 层直接 offline_map/{z}/{x}/{y}.png）
2. **MBTiles 单文件**：offline_map/任意名称.mbtiles（SQLite 标准瓦片容器，
   系统按 TMS 自动翻转行序，只读打开，不改你的文件）

识别成功标志：沙盘「图例/图层」出现「本地离线瓦片包」选项且默认选中；
载入失败会有红条提示，绝不显示假地图。

## 三、去哪里下载（按省事程度排序）

**范围建议**：演示场景为安康汉江一带，经度 107.3–107.8、纬度 33.0–33.4；
级别 8–16 足够指挥示意（要图上取点更准可到 17 级；全 18 级整市数据会到几十 GB，不建议）。

1. **天地图（官方，推荐）** <https://www.tianditu.gov.cn/>
   - 免费申请开发者密钥后，用下方任一工具把「天地图影像/矢量」下载成瓦片包；
   - 天地图为国家标准坐标系，与 GPS 采集数据基本一致，偏移远小于商用地图。
2. **水经微图** <https://www.rivermap.cn/>（国产桌面端，中文界面）
   - 框选范围 → 选择「天地图/高德/谷歌」图源 → 导出「MBTiles 或 XYZ 瓦片包」；
   - 对个人演示有免费额度。
3. **qMapTools（地图下载器）** <https://www.qmaptools.com/>
   - 同样支持导出 mbtiles/瓦片目录，选「离线包/瓦片缓存」类格式。
4. **MOBAC（Mobile Atlas Creator，免费开源）** <https://mobac.sourceforge.io/>
   - Java 桌面程序；自定义加天地图 WMTS 源后，导出格式选
     "MBTiles" 或 "OSDroid zip（解压即 tiles/{z}/{x}/{y} 结构）"。

> 注意：直接从网上批量抓公开瓦片站点（尤其 OSM 官方服务器）违反其使用政策，
> 系统不提供抓取工具，请使用有授权的下载器与图源。

## 四、验证清单

1. 把包放入目录 → 打开 /sand → 图例里出现并可勾选「本地离线瓦片包」；
2. 断网（拔网线/关 Wi-Fi）刷新沙盘：底图正常、标注正常、页面不出现红条；
3. 对照一处已知地标：若你下载的图源本身是加密坐标（如高德源导出的包），
   偏移提示同样适用——坐标严谨研判前，先人工核对一处基准点。

## 五、边界（与全局红线一致）

- 离线包只读，系统绝不改写；缺瓦片就是缺，不用假图填充；
- 影像/地图精度不改变标绘权威链：正式发布仍走核验链，参谋与推演不直接改写态势。
