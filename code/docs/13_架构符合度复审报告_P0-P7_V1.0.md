## 三、本轮修复（3 项）

1. **`verified-basis-for-l3` 政策规则**（§3.4 第 2 条）：L3+ 契约激活时，订单选项必须声明前置条件，且每条前置 claim 须为 VERIFIED 并由 AUTHORIZED 证据支撑（防御纵深复检证据信任级别）。无前置条件的选项不得承载 L3+ 动作。正反两用例入库。
2. **`GeneralQuestion.suggested_reply_by_version`**（§5.5）：请示携带版本钟建议答复期限；到期仅支持催办语义，绝不自动决断。旧快照向后兼容。
3. **`StaffPlan.rationale_disabled`**（§5.1）：编制计划自动说明未启用岗位及缘由。

## 五、遗留观察（非偏差）

- L3 政策的"前置条件"口径以选项声明为准——若未来选项声明了过窄的前置集合，政策强度随之变窄；建议控制面展示 L3 决策依据全链供将军目视复核；
- 相似经验检索仍为标签交集，语义级检索依赖本地嵌入基建（§6.2 vector 条款），维持 P7 后评估。
