# 人员与物资页定版 V0.2

> 页面路径：`/materials`
> 职责：长期维护「人员、中队、随队物资、物资点」基础底账；每次火情只生成到场快照和动态缺口结果。

## 1. 核心定位

- 不是仓库出入库系统，也不是只针对某一次火情的临时清单。
- 长期基础资源 + 事件到场快照 + 灭火进程缺口 + 补给建议。

## 2. 长期基础资源

- 人员库（姓名、手机号/账号、单位、固定岗位、工作组、中队、联系方式、人员类别、在职、是否可参与前指事件、备注、来源、更新时间）；

- 中队固定岗位；

## 3. 中队随队物资规则

- 每个中队维护一份完整固定携带清单。
- 每次中队到场默认携带全部登记物资，不逐次重录。

## 4. 每次火情到场快照

```text
人员刷码 → 匹配所属中队 → 更新到场状态
→ 读取该中队完整携带清单 → 生成当前事件到场物资快照
```

- 到场快照属于当前事件，不反向修改长期档案。
- 少带/损坏/无法使用只记录本次差异（登记数量、实际可用、差异、原因）。
- 自动列出：中队、到场人数、携带物资、数量、到场时间、状态。

## 5. 页面分区

1. 长期资源维护（人员/中队/岗位/编制/携带物资/物资分类/物资点）。
2. 本次火情到场情况（到场中队、人数、未到场中队、携带物资、到场数量、可用/消耗/损坏、缺口、更新时间）。
3. 物资缺口与补给建议。

## 6. 缺口计算

依据：到场人数、中队类型、灭火战法、火线长度、蔓延速度、处置时长、已执行任务、已反馈消耗、物资可用数量、物资点可补给数量。

缺口按严重程度：正常 / 即将不足 / 当前不足 / 已影响执行。

结果同步影响第二页：方案可行性、队伍执行状态、后勤告警、待决策事项、补给命令建议。

### 6.1 缺口分级定义

| 级别 | 含义 | 色 |
|---|---|---|
| 正常 | 数量充分 | `#2F7D68` |
| 即将不足 | 依据消耗速率将被耗尽 | `#B77A1A` |
| 当前不足 | 低于当前需求 | `#B77A1A` |
| 已影响执行 | 已阻断任务 | `#B84A42` |

### 6.2 缺口结果字段

## 7. 最近物资点

- 长期维护或外部物资系统接口（本次先预留接口并注明）。
- 字段：名称、位置、单位、联系人、电话、可供应物资、库存、更新时间、开放状态、预计装运时间、数据来源。
- 无真实库存数据显示「库存未知 · 等待物资系统接口」，不编造有货。

### 7.1 数据来源状态

| 来源 | 显示 |
|---|---|
| 本地维护 | 演示资源点数据 |
| 外部接口 | 显示接口状态/更新时间 |
| 未接入 | 「物资点库存接口：待接入」 |

## 8. 文件导入

- 支持 Word / Excel / PDF / TXT / CSV，后续图片表格与扫描件 OCR。
- 对象：人员信息表、中队编制、中队携带物资、物资点清单、物资点库存。
- 流程：上传 → 选择数据类型 → 解析 → 字段映射 → 预览 → 查重/查错 → 生成草稿 → 授权发布 → 更新长期库。
- 扫描 PDF OCR 结果标记「OCR 解析 · 待人工复核」，未确认字段不入正式档案。
- 保留原始文件、哈希、上传人/时间、版本、错误清单，支持回滚与版本对比。

### 8.1 导入状态机

```text
已上传 → 解析中 → 待映射 → 预览 → 已生成草稿 → 已发布
                                          ︈ 失败（错误清单）
```

| 状态 | 含义 |
|---|---|
| 已上传 | 文件进入 |
| 解析中 | 解析表格/OCR |
| 待映射 | 字段未确定 |
| 预览 | 展示结果待确认 |
| 已生成草稿 | 待授权发布 |
| 已发布 | 写入长期库 |
| 失败 | 有错误清单，可重导 |

### 8.2 导入记录字段

| 字段 | 说明 |
|---|---|
| 原始文件 / 文件名 / 类型 / 哈希 | 溯源 |
| 上传人 / 上传时间 | 	 |
| 数据类型 | 人员/编制/物资/物资点/库存 |
| 解析状态 / 错误数量 | 	 |
| 导入版本 / 发布人 / 发布时间 | 版本管理 |

### 8.3 字段映射与错误

- 自动识别常见列名（姓名/手机号/单位/岗位/工作组/物资名称/数量/单位/中队）。
- 错误清单：姓名为空、手机号格式错、重复手机号、岗位/工作组不存在、单位缺失、非数字数量、中队无法匹配、重复物资、OCR 识别不完整。
- 支持重新导入、回滚、版本对比。

## 9. 数据状态边界

- 长期档案与事件快照分开。
- 火情结束后：快照进入复盘；长期档案只在授权维护后更新。
- 不因某次损坏覆盖长期装备档案；不因某次未到场删除长期人员。

## 10. 权限

- 授权维护人员：维护长期人员/队伍/物资/物资点。
- 指挥员：查看当前事件资源、确认到场与缺口、确认补给建议。
- 普通人员：查看授权范围。
- 中队人员：查看本中队人员、物资、缺口。
- 智脑：读取、计算缺口、提补给建议，不能改长期档案。
- 公共屏：只显示已发布到场统计和公开资源状态。

## 11. 闭环

```text
长期维护底账 → 中队到场刷码 → 自动加载随队物资
→ 生成到场快照 → 按进程计算消耗与缺口
→ 查找最近物资点 → 显示补给建议
→ 后续接入物资系统实时库存 → 全部变化进入复盘
```
