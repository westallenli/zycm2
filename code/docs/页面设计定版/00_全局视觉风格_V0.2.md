# 全局视觉风格定版 V0.2

> 适用于森林草原火灾前线指挥调度平台全部前台页面。
> 定位：浅色前指值守工作台，不是宣传式 AI 产品。

## 1. 设计基调

- 正式前指值守系统观感，重点表达「组织、态势、人员、物资、命令、反馈」。
- 不以 AI 为主角，不出现「智脑正在工作 / 参谋部正在收集」等 AI 自述框。
- 色彩克制、信息密度高、层级清晰、状态一眼可辨。

## 2. 禁止项（硬约束）

- 不使用旧的深绿、橙黄、米色混搭。
- 不使用大面积渐变、发光、AI 紫色。
- 不使用厚重圆角卡片堆叠的宣传式 AI 产品感。
- 不出现大面积装饰性卡片、花哨图标堆砌。

## 3. 色板

| 用途 | 色值 |
|---|---|
| 页面底色 | `#F3F5F7` |
| 内容区底色 | `#FFFFFF` |
| 主文字 | `#1F2D3A` |
| 次文字 | `#647382` |
| 边框 | `#D9E0E6` |
| 主色 | `#245B78` |
| 正常 / 已确认 | `#2F7D68` |
| 待核验 / 注意 | `#B77A1A` |
| 高风险 / 告警 | `#B84A42` |
| 地图底色 | `#DCE5E4` |
| 火线 | `#C95B45` |

### 语义对照

- 主色 `#245B78`：主导航、主按钮、选中态、链接。
- 正常 `#2F7D68`：已确认、已发布、已完成、在线/已到场。
- 待核验 `#B77A1A`：待核验、注意、待验证、弱告警。
- 高风险 `#B84A42`：告警、关键、未通过、高风险、通信异常。

## 4. 布局规范

- 页面底色 `#F3F5F7`，内容卡片用白底 + `1px` `#D9E0E6` 边框。
- 圆角统一小半径（约 4px），不做大圆角。
- 信息用表格、筛选栏、详情栏、状态行表达，优先级：列表/表格 > 卡片。
- 顶部栏、侧面主区、右侧详情侧栏、底部时间线为通用骨架。

## 5. 状态表达

- 静默高亮：用主色描边或浅灰填充标记选中。
- 告警用少量信号色点缀，不用整块大面积红/黄。
- 数据缺口、未确认项用次文字或灰色表达，不伪装成已有数据。

## 6. 数据性质标注

- 演示数据、模拟轨迹、待联调、待接入接口，必须在界面明确标注。
- 无记录/缺失数据显示「暂无记录 / 数据缺失 / 待补充」，不得补写。

## 7. 组件级规范

### 7.1 按钮

| 类型 | 背景 | 文字/边框 | 用途 |
|---|---|---|---|
| 主按钮 | `#245B78` | 白字 | 主要操作 |
| 次按钮 | 白底 | `#245B78` 字 + 1px `#245B78` 边 | 次要操作 |
| 危险按钮 | 白底 | `#B84A42` 字 + 1px `#B84A42` 边 | 驳回/删除/撤回 |
| 确认-成功按钮 | `#2F7D68` | 白字 | 确认发布/通过 |
| 文字按钮 | 透明 | `#245B78` 字 | 轻量链接式操作 |
| 禁用 | `#F3F5F7` | `#647382` 字，无边框 | 不可用 |

规则：
- 高度统一（约 32px），内边距左右 12px；
- 圆角 4px；
- 一个操作区内主按钮不超过一个；
- 危险动作需二次确认，不用醒目的整块红底（用描边红即可）。

### 7.2 表格

- 容器：白底 + `1px` `#D9E0E6` 边框 + 4px 圆角。
- 表头：`#F3F5F7` 底，主文字粗体，行高稳定。
- 行分隔：`1px` `#D9E0E6` 下边框，不用斑马纹。
- 悬停行：`#F3F5F7` 底，用于对齐视线。
- 选中行：`#245B78` 描边或极浅蓝底，与其他高亮区分。
- 数字列右对齐，文本列左对齐。
- 状态列用色点/胶囊 + 文字，不用纯色整格。
- 空单元格显示 `—`，不显示空白或补写。

### 7.3 表单

- 标签：主文字，必填项以 `*` 标红（`#B84A42`），不加花哨图标。
- 输入框：白底 + `1px` `#D9E0E6` 边 + 4px 圆角；聚焦主色描边。
- 错误态：`#B84A42` 描边 + 错误提示文字（次文字下方）。
- 必填校验、字段映射、预览均在表单内完成，不弹遮挡式大弹窗。
- 同一表单提交按钮位置固定，主按钮居右。

### 7.4 告警条

| 级别 | 背景 | 左侧色条 | 文字/图标 |
|---|---|---|---|
| 高风险 | `#FBF0EF` | `#B84A42` | 深红/醒目 |
| 注意 | `#FBF6EC` | `#B77A1A` | 深黄 |
| 正常/成功 | `#F0F7F4` | `#2F7D68` | 深绿 |
| 中性提示 | `#F3F5F7` | `#647382` | 深灰 |

规则：
- 左侧竖色条标识级别，不用整块大色底；
- 文案短，动作链接明确；
- 可关闭、可点击定位到对应对象；
- 未读告警在顶栏用少量红点计数，不整条飘红。

### 7.5 空态 / 缺失态

| 场景 | 展示 |
|---|---|
| 无数据 | 「暂无记录」+ 可选引导操作 |
| 数据缺失 | 「数据缺失 · 待补充」 |
| 待接入 | 「待接入」或「接口待接入」 |
| 底图异常 | 「底图不可用」 |

规则：
- 用次文字 + 细边框虚线框表达，不用大插画/满屏空白；
- 不补写数据、不伪造成功；
- 有可触发动作时提供引导按钮，否则仅说明。

### 7.6 标签 / 徽标

| 语义 | 色 |
|---|---|
| 已确认/已完成/已发布 | 浅绿底 `#2F7D68` 字 |
| 待核验/待确认 | 浅黄底 `#B77A1A` 字 |
| 告警/关键 | 浅红底 `#B84A42` 字 |
| 草稿/AI 候选 | 浅灰底 `#647382` 字 |
| 已撤销/失效 | 浅灰底 `#647382` 字 + 删除线 |

规则：
- 胶囊形，小圆角，小字号；
- 色块用浅底 + 深字，不用高饱和整块。

### 7.7 导航 / 页签

- 顶栏：主色 `#245B78`，当前页白色文字或高亮。
- 侧栏/页签：选中态用 `#245B78` 文字 + 底部 2px 色条或浅蓝底，不用厚重色块。
- 面包屑次文字，层级清晰。

### 7.8 图标

- 线性图标，统一描边，尺寸一致（16/20/24px）。
- 不加发光/渐变/拟物效果。
- 图标辅助文字，不单独承担语义。

### 7.9 间距与密度

- 高密度布局：卡片间距 12px，行内 8px，内边距 12–16px。
- 主区与侧栏之间有 `1px` `#D9E0E6` 分隔。
- 字号基线：正文 14px，标题 16/18/20px 层级递增，次文字 13px。
