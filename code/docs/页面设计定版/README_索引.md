## 通用约束（跨页）

1. 浅色前指工作台视觉，详见 00 号文件，不混旧深绿/橙黄/米色风格。
2. 熊猫智脑/参谋是后台受控岗位，前台只见业务结果，不出现 AI 自述框。
3. 事实/判断/建议/指令严格分层；草稿/待核验/已核验/已发布状态贯穿。
4. 权力链纪律：AdvisorProposal → GeneralDecision → ExecutionOrder → Policy/Approval → Executor；决断权只在指挥员；append_event 唯一写入口。
5. 演示数据/模拟轨迹/待联调/待接入接口必须显式标注，不得伪装为已接入能力。
