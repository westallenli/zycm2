# 指挥调度沙盘页定版 V0.2

> 页面路径：`/sand`
> 职责：指挥员核心工作页。态势、决策、命令、执行闭环；熊猫智脑后台能力在此以业务结果可见。

## 1. 页面结构

- 顶部：事件名称、编号、响应等级、事件状态、当前阶段、数据截至时间、当前登录人员、通信状态、未读 P0/P1 告警。
- 左侧：总体目标、现场阶段、待决策事项、决策历史。
- 中间：火场指挥调度地图。
- 右侧：当前态势、告警、信息缺口、待决策事项、方案比较、指挥员决断、命令确认、执行反馈。

## 2. 阶段状态机

火情响应 → 初期侦查 → 态势形成 → 资源调配 → 方案决策 → 命令执行 → 异常处置 → 收尾复盘

- 方案选择与命令下达拆成两个动作。
- 阶段由真实事件状态驱动，不伪造推进。

### 2.1 阶段状态表

| 阶段 | 进入条件 | 关键动作 | 退出条件 |
|---|---|---|---|
| 火情响应 | 接警/建事件 | 建任务空间、发二维码、编队 | 前指成立并开始侦查 |
| 初期侦查 | 前指成立 | 信息收集、图像导入 | 首轮态势发布 |
| 态势形成 | 首轮证据齐 | 汇总事实、定火线/危险区 | 态势版本发布 |
| 资源调配 | 有明确目标 | 核对队伍/物资 | 资源到位或确认缺口 |
| 方案决策 | 态势+资源 | 生成≤3方案、比较、决策 | 指挥员定案 |
| 命令执行 | 方案确认 | 下达、接收、反馈 | 任务完成或异常 |
| 异常处置 | 异常发生 | 暂停、重新研判 | 新方案确认 |
| 收尾复盘 | 事件结束 | 汇总、复盘 | 复盘发布 |

## 3. 地图对象分类

- 区分：事实 / 判断 / 建议 / 指令。
- 状态：草稿、待核验、已核验、已发布、已撤销。
- 无人机或参谋产生的标注不能直接成为正式火线。
- 队伍地图区分：计划路线、建议路线、确认路线、实际轨迹。

### 3.1 对象分类定义

| 分类 | 含义 | 示例 |
|---|---|---|
| 事实 | 观测得到，有证据 | 无人机影像、瞭望塔、卫星热点 |
| 判断 | 分析推断 | 推定火线、危险区 |
| 建议 | 智脑/参谋建议 | 候选标注、建议路线 |
| 指令 | 正式命令 | 确认路线、控制线 |

### 3.2 状态与流转

```text
草稿 → 待核验 → 已核验 → 已发布
  └→ 已撤销（保留历史）
```

| 状态 | 含义 |
|---|---|
| 草稿 | 本机作业中 |
| 待核验 | 提交等待确认 |
| 已核验 | 授权核实通过 |
| 已发布 | 进入共享态势 |
| 已撤销 | 作废，历史保留 |

### 3.3 路线类型

| 路线 | 含义 |
|---|---|
| 计划路线 | 预案/规划 |
| 建议路线 | 智脑/参谋建议 |
| 确认路线 | 指挥员确认正式路线 |
| 实际轨迹 | 队伍真实行进 |

## 4. 执行状态

草稿 / 待确认 / 已下达 / 已接收 / 执行中 / 受阻 / 暂停 / 已完成 / 异常 / 撤回

- 异常时命令暂停/冻结，生成新的待决策事项，由指挥员重新研判。

### 4.1 执行状态定义

| 状态 | 含义 |
|---|---|
| 草稿 | 待确认命令 |
| 待确认 | 指挥员确认前 |
| 已下达 | 命令发出 |
| 已接收 | 执行方回执 |
| 执行中 | 执行进行 |
| 受阻 | 遇到阻碍 |
| 暂停 | 冻结等待重判 |
| 已完成 | 完成并验证 |
| 异常 | 异常待处理 |
| 撤回 | 撤销，历史保留 |

### 4.2 命令状态流转

```text
草稿 → 待确认 → 已下达 → 已接收 → 执行中 → 已完成 / 异常
                                      ︈ ↑ 受阻/暂停 → 重判
任何状态 → 撤回（保留历史）
```

## 5. 地图与右侧双向联动

- 点击右侧风险定位地图。
- 点击地图对象展开态势与待决策。
- 切换方案只预览地图变化，未确认不修改正式态势。
- 命令下达后才更新正式路线与队伍任务。

## 6. 底图

- 使用免费真实在线地图，支持快速加载、拖动、缩放、真实地理位置、点线面对象、业务图层解耦。
- 底图异常显示「底图不可用」，不能把空白当正常。
- 底图（基础地图）与证据图层、业务图层解耦。

## 7. 图层

- 证据图层：无人机影像、卫星热点、瞭望塔、地面巡护、现场照片、气象、兵力定位、其他系统空间数据。
- 业务图层：疑似/确认火点、疑似/确认火线、危险区、过火区、隔离带、队伍、指挥部、水源、物资点、医疗点、重点设施、计划/建议/确认路线、实际轨迹、通信盲区。
- 所有图层支持：开关、透明度、顺序、来源、采集时间、核验状态、权限查看。

### 7.1 图层对象字段

| 字段 | 说明 |
|---|---|
| 图层名称/类型 | 证据 or 业务 |
| 来源 | 系统/无人机/其他系统 |
| 采集时间 / 上传时间 | 双时间 |
| 核验状态 | 草稿/待核验/已核验/已发布 |
| 权限 | 可见角色 |
| 默认开关/透明度/排序 | 展示配置 |

### 7.2 图层控制

- 开关：单图层显隐；
- 透明度：0–100%；
- 顺序：图层叠加次序；
- 权限可见：按角色过滤，公共屏只显示已发布图层；
- 配置可保存为图层方案。

## 8. 地图工具

必须提供：火点、指挥部、水源、物资点、隔离带、起降点，以及画线、画面(多边形)、画圈、箭头、文字、测距、测面积、编辑、撤销、重做。

## 9. 无人机图像导入

- 支持 JPG、PNG、带空间范围影像、其他系统截图；预留 GeoTIFF、正射影像、热成像、瓦片、视频帧、实时视频流。
- 流程：选择图像 → 读取来源和采集时间 → 判断空间定位 → 自动定位或人工配准 → 叠加到地图 → 设置透明度/顺序 → 智脑分析 → 生成疑似火点/火线 → 等待指挥员确认。
- 图像记录：图像编号、来源系统、采集单位、采集时间、上传时间、类型、空间范围、定位精度、图像状态、是否已分析、是否已核验、关联事件。
- 有空间信息自动定位；无空间信息人工配准（拖动/缩放/旋转/控制点/覆盖范围）。
- 未配准图像只能是「未配准证据」，不能用于正式火线/路线判断。

### 9.1 图像状态机

```text
已上传 → 待配准/已定位 → 已叠加 → 智脑分析中 → 已生成候选 → 已确认/已驳回
                                        ︈ 未配准 → 仅作未配准证据
```

| 状态 | 含义 |
|---|---|
| 已上传 | 导入未处理 |
| 待配准 | 无空间信息待人工配准 |
| 已定位 | 有空间信息自动定位完成 |
| 已叠加 | 已叠到地图 |
| 分析中 | 智脑识别中 |
| 已生成候选 | 产出候选标注 |
| 已确认/已驳回 | 指挥员处理 |

## 10. 智脑候选标注

- 智脑可生成：疑似火点、疑似火线、烟雾方向、火势扩展方向、疑似危险区、重点目标威胁区、队伍位置候选、影像变化区。
- 标注状态必须明确显示：智脑识别·待确认 / 智脑建议·待核验 / 指挥员已确认 / 已发布共享 / 已驳回 / 已撤销。
- 候选标注以虚线/半透明区分于正式火线。
- 右侧待确认卡片：来源图像、采集时间、识别时间、置信度、影响范围、与既有火线关系、定位地图、查看原图、编辑、确认发布、驳回。
- 确认后形成新态势版本，记录确认人/时间，进入时间线，可被方案/任务引用；驳回保留原图与智脑结果，记录原因，不进入正式态势。

### 10.1 标注类型与字段

| 类型 | 字段 |
|---|---|
| 疑似火点/火线 | 来源图像、识别时间、置信度、坐标 |
| 烟雾/扩展方向 | 方向、风速关联、置信度 |
| 危险区/威胁区 | 范围、目标、分析依据 |
| 队伍位置候选 | 候选点、来源、可信度 |
| 影像变化区 | 前后影像、变化类型 |

通用字段：标注编号、类型、来源图像、采集时间、识别时间、置信度、影响范围、与既有火线关系、定位地图、状态。

### 10.2 标注状态机

```text
智脑识别·待确认 → 指挥员已确认 → 已发布共享
               ↘ 智脑建议·待核验 → 已发布共享
               ↘ 已驳回（保留原因）
智脑识别·待确认 → 已撤销
```

已发布标注可被方案/任务引用；已驳回/已撤销不进入正式态势，但保留原图和智脑结果。

## 11. 自由区域测算

- 非正圆/椭圆/固定多边形，鼠标或触摸任意轨迹，松开自动闭合。
- 计算面积和周长，支持待核查区、火场范围、危险区、过火区、重点保护区、隔离带。
- 临时测量与正式标绘分离。
- 保存为业务对象流程：草稿 → 提交核验 → 指挥员确认 → 发布共享。

### 11.1 测算结果字段

| 字段 | 说明 |
|---|---|
| 区域类型 | 待核查区/火场/危险区/过火区/重点保护区/隔离带 |
| 面积 | 计算结果（含单位） |
| 周长 | 计算结果 |
| 轨迹 | 手绘闭合路径 |
| 状态 | 临时 / 草稿 / 待核验 / 已核验 / 已发布 |
| 保存人/时间 | 审计 |

### 11.2 临时与正式分离

- 临时测量：查看面积/周长后关闭，不落库。
- 保存为业务对象：进入草稿 → 提交核验 → 确认 → 发布。
- 触摸路径：后续需兼容手指绘制。

## 12. 权限

- 指挥员：导入图像、查看原图、编辑/确认/驳回标注、发布态势、自由绘制、选择方案、确认命令。
- 其他到场人员：查看授权范围地图、发布图层、智脑候选标注、已发布结果、执行反馈；可使用问询；不能编辑/发布/选方案/下令/改岗/改物资。
- 公共屏：只显示已发布内容，不显示未发布标注和原始图像。

### 12.1 权限矩阵

| 动作 | 指挥员 | 其他到场人员 | 公共屏 |
|---|:-:|:-:|:-:|
| 导入图像/查看原图 | ✓ | ✗ | ✗ |
| 编辑/确认/驳回标注 | ✓ | ✗ | ✗ |
| 发布态势 | ✓ | ✗ | ✗ |
| 自由绘制/测算 | ✓ | ✗ | ✗ |
| 选择方案/确认命令 | ✓ | ✗ | ✗ |
| 查看发布图层/结果 | ✓ | ✓ | ✓ |
| 查看智脑候选标注 | ✓ | ✓ | ✗ |
| 使用问询 | ✓ | ✓（限权限） | ✗ |

## 13. 态势问询

- 支持文字、语音、语音转文字、证据化回答、地图定位、原始来源查看。
- 指挥员可问：当前火线、最新无人机图像、队伍位置、水源、未核实信息、待决策事项、区域面积、路线风险、方案影响。
- 回答必须带：结论、数据时间、来源、地图位置、置信度、未确认内容。
- 语音识别为问询时只检索数据，不改状态。
- 语音识别为命令时转为命令草稿（显示执行单位、区域、状态），经指挥员确认后才进入 ExecutionOrder → Policy/Approval → Executor。
- 其他人员说出命令只能得无权限提示或转为建议，不能下达。

### 13.1 问询回答字段

| 字段 | 说明 |
|---|---|
| 结论 | 直接可读回答 |
| 数据时间 | 引用的数据截止时间 |
| 来源 | 数据/证据来源 |
| 地图位置 | 定位坐标或对象 |
| 置信度 | 高/中/低 |
| 未确认内容 | 仍待核验的部分 |

### 13.2 语音意图分流

| 意图 | 处理 |
|---|---|
| 问询 | 只检索数据，不改状态 |
| 命令（指挥员） | 转命令草稿 → 指挥员确认 → ExecutionOrder |
| 命令（其他人员） | 无权限提示或转建议，不执行 |
