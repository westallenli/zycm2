## 3. 动态叠加层

动态层只能放在原图外部或不遮挡原图内容：

- 当前登录人员高亮；
- 组织框外叠加已到场/未到场、到场人数、通信异常；
- 点击组织框后右侧显示人员列表；
- 当前登录人员详情显示姓名、岗位、单位、联系方式、到场时间。

### 3.1 叠加层对象字段

| 对象 | 字段 |
|---|---|
| 组织框 | 岗位名（原图原样）、到场人数/编制人数、到场率、所属组 |
| 人员 | 姓名、单位、固定岗位、工作组、中队、联系方式、到场时间、登录/通信状态 |
| 当前登录人 | 额外高亮标记 + 本人详情卡 |
| 通信叠加 | 正常 / 较弱 / 异常，异常在框外点缀示警 |

### 3.2 到场/通信状态定义

| 状态 | 含义 | 色 |
|---|---|---|
| 已到场 | 刷码完成写入到场 | `#2F7D68` |
| 未到场 | 在名册但未刷码 | `#647382` |
| 通信异常 | 到场但通信中断/失联 | `#B77A1A` |
| 通信正常 | 已到场且通信在线 | `#2F7D68` |
| 失联 | 长时间无通信，需关注 | `#B84A42` |

### 3.3 状态流转

```text
在名册(未到场) → 刷码 → 已到场
已到场 → 离场/撤离 → 已撤离
已到场 + 通信中断 → 通信异常 → 恢复 → 通信正常
通信异常超时 → 失联 → 恢复通信 → 已到场
```

## 5. 数据来源

- 到场状态、工作组人数、通信状态、当前登录人信息来自第三页「人员与物资」的长期人员库 + 本次到场快照。
- 不做本地伪数据；未到场/未导入明确标注。

### 5.1 右侧人员列表字段

点击组织框，右侧显示：

- 岗位/组名；
- 人员姓名、固定岗位；
- 到场状态；
- 到场时间；
- 通信状态；
- 联系方式（按脱敏规则）；
- 当前任务（如有）；
- 数据更新时间。

- 岗位结构永远由原图呈现，不写入、不重排。
- 叠加仅发生在原图之外或空白处，不遮挡任何原图文字。
