## 3. 为什么之前只有 admin

我这版原来跑的是 `panel` 的**演练态**（`load_state(demo=True)`），那条路径**没有人员库**：没有 120 人名册、没有任命关系、没有值班绑定。所以：

- 只能用 `admin` 登
- 看到的页面是按指挥员/值班那条线走的，不是你老版本里副指挥长看到的那套

现在改成走 `resource_demo.open_state(demo_data)`——老交付的装配路径，人员库、任命、值班绑定、事件快照全都在，所以三种身份回来了。
