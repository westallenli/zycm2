# 熊猫智脑 面板命令面扩围评估 V1.0

> 文档定位：回答"哪些指挥动作可以安全地放进本地控制面板"。逐动作对照工作区的将军入口门禁（`workspace.py` 11 处 `_require_general_entry()`）与政策规则（`no-challenged-basis` / `declared-boundary` / `verified-basis-for-l3`）给出结论。**本文只评估，不实施**——任何扩围落地另行拆解报批。
>
> 核对基线：P12-T2 与 `impl/panda_brain/workspace.py`、`panel.py` 当前实现逐项核对。

---

## 一、评估维度

| 维度 | 问的问题 |
|---|---|
| 不可逆性 | 动作是否走向不可逆结局（如 cancel）？ |
| 误触代价 | 网页一键误发的后果多大？可否撤销？ |
| 上下文需求 | 决断是否依赖参谋流程的完整上下文（对比矩阵、政策检查输出）？ |
| 复检严肃性 | 是否存在"必须停下来想"的设计意图，一键会削弱它？ |
| 表单复杂度 | 所需输入能否在小表单里诚实呈现？ |

## 二、门控动作逐项评估

工作区共 11 个将军门控方法。面板 v1 已收编 2 个，其余 9 个评估如下：

| 动作 | 危险度 | 结论 | 依据 |
|---|---|---|---|
| `answer_general_question` | 低 | **已入 v1**（含异常答复自动 `resume_order` 联锁） | 请示本身就是"停下来问将军"的设计，网页答题与其语义一致 |
| `confirm_memory_candidate` | 低 | **已入 v1**（确认/拒绝双钮） | 受控记忆两红线由结构保证，确认动作无事实副作用 |
| `pause_order` | 低-中 | **v2 可入**：有 `resume_order` 对偶、可恢复；表单须强制填写原因 | 暂停是保守方向的动作，误触代价小 |
| `resume_order` | 中 | **维持随请示流**（现状），不开独立入口 | P4 设计了恢复前复检；独立按钮会把"复检"弱化成"点一下" |
| `cancel_order` | 高 | **暂不入**：不可逆结局；若将来入，须理由必填 + 二次确认 + 口令复验 | 取消走向终态，无对偶恢复 |
| `record_feedback` | 低 | **缓**：反馈在参谋流程内消费才有意义，网页单发表单价值有限 | 反馈对象是 AdvisorProposal，脱离提案上下文的裸反馈易失真 |
| `add_commander_option` | 中 | **已落地（P14-T1，2026-08-22）**：精简表单（标题/概述必填+CSV 可选字段+可逆性下拉），配重新参谋入口形成闭环 | PROPOSE 自提流已有测试覆盖，P14 补齐录入界面与重排闭环 |
| `confirm_goal_frame` | 低 | **v2 候选**：目标视图加确认钮即可 | 低频低危，语义就是"将军看过并认可" |
| `record_decision` / `confirm_order` / `record_approval` | **最高** | **不进网页**（v1/v2 均否） | 见第三节专述 |

## 三、命令链三连为何不进网页

起草→确认→审批是权力链最重的三步，其中 `record_approval` 叠加双重拦截：

1. L3+ 契约受 `verified-basis-for-l3` 政策约束——订单选项**前置条件** claim 必须全部 VERIFIED 且证据源 AUTHORIZED（P8-T1 修复口径：管"依据"而非全部 claims）；
2. `Approval` 五要素绑定 + 有效期（P4，以 +2 余量解决差一问题）+ resume 复检。

这三步的价值恰恰在于**强迫深思熟虑**。网页一键的交互本性与之相悖——这不是技术做不到，而是不该做快。若远期确需入面板，最低门槛：

- **两屏制**：第一屏完整渲染 ActionContract、政策检查结果、前置条件证据清单；第二屏要求口令复验（重新过 `GeneralEntryAuth.authenticate`）+ 手工输入订单 ID 全文匹配；
- **审计留痕**：相关事件载荷增加 `origin: "panel"` 标注，事后可区分面板发起与 CLI/代码发起；
- **失败即中断**：任一政策检查不过直接 409 终止，绝不给"强行继续"选项。

## 四、结构性排除项（不属于"动作"，永远不进网页）

- 一切绕过摄取桥直改 claim/evidence 的入口——数据面纪律（docs/15）不允许旁路；
- `propose_memory_candidate`——复盘流程自动产出，不是将军输入；
- 工作区删除/重置——快照文件管理属文件系统操作，留在命令行。

## 五、结论与建议路线

- **v1（现状）**：答请示 + 记忆确认/拒绝 + 只读六视图 + 时间线审计 —— 维持不变；
- **T4 已并入本阶段**：战后报告导出（纯只读，零权力含义）；
- **v2 首批（已落地，P13-T1/T2，2026-08-22）**：`pause_order`（原因必填入 OrderPaused 审计事件）+ `confirm_goal_frame`（简报视图确认钮，过 chief 真认证路由）；
- **持续排除**：命令链三连、`cancel_order`（除非接受第三节的最低门槛）、一切数据面写旁路。
